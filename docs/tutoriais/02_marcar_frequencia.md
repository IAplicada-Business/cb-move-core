# Tutorial 02: Marcar frequência
**Duração estimada:** 2–3 min

## Introdução (10s)
"Neste tutorial você vai aprender a registrar a presença ou ausência dos pacientes nas sessões. Vamos ver como é simples!"

## Passos

### 1. Acessar Frequência
**Mostrar na tela:** Sidebar com item "Frequência" destacado.
**Falar:** "No menu lateral, clique em Frequência — está no grupo Operação, logo abaixo de Agenda."

### 2. Selecionar a data
**Mostrar na tela:** Seletor de data com mês e dia visíveis.
**Falar:** "Escolha a data da sessão que você quer registrar. Você pode navegar entre os dias usando as setas ou clicando diretamente no calendário."

### 3. Ver a lista de pacientes do dia
**Mostrar na tela:** Lista de pacientes agendados para aquela data.
**Falar:** "O sistema mostra automaticamente os pacientes que têm sessão neste dia. Para cada um, você vai marcar o que aconteceu."

### 4. Marcar a frequência de cada paciente
**Mostrar na tela:** Botões P, F, FJ, RC, NJ, NR com cores diferentes.
**Falar:** "Clique no botão correspondente para cada paciente:
- P significa que o paciente compareceu
- F significa que faltou sem avisar
- FJ é falta justificada — avisou com antecedência
- RC é sessão de reposição
- NR é quando não houve atendimento naquele dia"

### 5. Adicionar observação opcional
**Mostrar na tela:** Campo de texto de observações aberto abaixo do nome do paciente.
**Falar:** "Se quiser, você pode digitar uma observação para aquela sessão — por exemplo, 'paciente relatou dor lombar' ou 'sessão cancelada por feriado'."

### 6. Salvar
**Mostrar na tela:** Botão Salvar sendo clicado e confirmação aparecendo.
**Falar:** "Clique em Salvar para confirmar os registros do dia. Tudo fica salvo automaticamente no prontuário de cada paciente."

## Encerramento (10s)
"Pronto! A frequência está registrada. Esses dados alimentam automaticamente os relatórios financeiros e o histórico de cada paciente."
